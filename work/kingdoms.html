TownPDCRace

Связка систем для игрового сервера: королевства, расы, ресурсы чанков и мини-карта. Плагины стояли на Purpur 1.21, на сервер заходили и другие игроки.

Правила задавал я. Приглашение в королевство и передача главы проходят только с подтверждением. Коллекторы защищены так же, как ратуша. Ресурсы восстанавливаются в чанках с коллекторами, а список этих чанков берётся из плагина королевств. Меню рас собрано по сетке 256×256, кликабельны только слоты предметов.

В игре я поймал несколько поломок. Два игрока в одном меню коллектора получали дубликат предмета. Коллектор и склад тоже двоились. Мула сдвигали поршни. Флаг падал вместе с блоком. По владельцу ратуши всплывало нарушение уникальности. Кастомный динамит после рестарта становился обычным: хранение в файле я отклонил и оставил Persistent Data Container чанка.

Пакеты, события, SQLite и API между плагинами собирал AI-агент. Исходники приватные. Между сессиями работа над системами ставилась на паузу.
